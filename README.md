# SM02 Emulator
**Currently a work in progress!**

## Description
The SM02 is a CPU created in Scrap Mechanic, and this project emulates it.

## Installation
Install SFML and nlohmann/json. Clone the project in Visual Studio. In the project properties, set the correct additional include and additional library directories, and add sfml-graphics.lib to additional dependencies if not already added.

## Usage
To run the emulator, start the project in Visual Studio.

To change the program, use the SM02 Assembler, and replace the data.json file in the emulator with the output from the assembler.
